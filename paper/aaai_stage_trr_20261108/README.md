# AAAI-style draft

This directory contains an evidence-first draft centered on Stage-Aware
Two-Timescale Readout Refinement.

- `main.tex`: readable AAAI-style draft using a standard LaTeX fallback.
- `references.bib`: related-work and dataset references.
- `evidence_map.md`: mapping from claims to executed artifacts.

The draft intentionally distinguishes exploratory frozen comparisons from
confirmatory evidence. Install the official AAAI style files before a venue
submission. The local environment did not include `pdflatex`, so PDF
compilation remains pending.
